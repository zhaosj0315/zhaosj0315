## 🎨 核心理念

* **🌱 长期主义**：不写一次性的玩具，将所有公开的产品作为长线生命体进行维护与高标准修正。
* **🧩 真实痛点**：拒绝盲目套用热门概念。优先验证生活中是否有对应需求，再考虑它的实现形态。
* **🔒 本地优先 (Local-First)**：用户始终拥有数据所有权，断网可用，无侵入式云端传输。
* **🤝 公开构建 (Build in Public)**：坚持通过技术博客与开源仓库，诚实记录折腾与演进的过程。
